# Interactive Robot Desk Buddy
 
## Overview
 
The **Interactive Robot Desk Buddy** is an animated Arduino-powered companion designed to bring personality and interactivity to any workspace. Using a combination of **light, force, and distance sensors**, the robot responds dynamically to its environment and the user's actions in real time.
 
An LCD screen displays expressive animated faces that change according to the robot's current mood, while a buzzer plays matching sound effects to enhance each emotional state. The robot can wake up when it detects activity, fall asleep in darkness, laugh when gently "tickled," and become annoyed when squeezed too forcefully.
 
The Desk Buddy also monitors personal space using a distance sensor. If someone leans too close, it reacts with expressions and sounds, creating the impression of a living desktop companion. For added entertainment, the system includes a built-in **side-scrolling obstacle game** that can be launched directly on the LCD screen, providing a quick and fun study break.
 
This project combines **multi-sensor input processing, state-based programming, animated visual feedback, and audio interaction** into a beginner-friendly embedded systems project. It demonstrates core Arduino concepts while creating an engaging and personality-driven user experience that is both educational and entertaining.
 
## Features
 
- **Light Sensor Integration**
- Detects ambient light levels.
- Transitions between awake and sleep states.
 
- **Force Sensor Interaction**
- Responds to gentle touches and strong squeezes.
- Triggers different emotional reactions.
 
- **Distance Sensing**
- Detects when a user is too close.
- Generates unique expressions and sounds.
 
- **Animated LCD Display**
- Shows dynamic facial expressions.
- Reflects the robot's emotional state.
 
- **Audio Feedback**
- Uses a buzzer to play sounds and melodies.
- Enhances the robot's personality.
 
- **Built-in Mini Game**
- Side-scrolling obstacle avoidance game.
- Playable directly on the LCD screen.
 
## Learning Outcomes
 
This project demonstrates:
 
- Reading and processing data from multiple sensors.
- Implementing finite state machine (FSM) logic.
- Generating visual animations on an LCD display.
- Producing audio feedback using a buzzer.
- Designing interactive embedded systems with Arduino.
- Creating engaging user experiences through hardware and software integration.
